规则：

- 一行一个“平台 × 商品”，同商品多平台分行。
- 到手价写实付，不写标价；标价放“优惠条件”里。
- 折合单价必须算，方便跨规格比较。
- 链接用原始商品/爆料链接，不用短链。
- 排序：折合单价升序；同价按难度升序。

## 难度分级

| 难度 | 类型 | 判定 | 是否推荐 |
|---|---|---|---|
| 易 | 直接买 | 标价即到手，无券无凑单 | ✅ |
| 较易 | 领券 | 页面券/店铺券，一键领 | ✅ |
| 较难 | 凑单/会员 | 需凑满减/凑单品，或需 PLUS/88VIP/会员价 | ✅（标凑单金额/会员条件） |
| 难 | 秒杀/直播间 | 限时、需蹲、需红包 | ⚠️ 标“需蹲” |
| 很难 | 拼团/福袋 | 需拉人成团，或百亿补贴福袋/概率券 | ❌ 默认不推荐 |

“很难”如果用户明确要，单独列“不确定项”，不进主表排序。

## 时效规则

| 爆料更新时间 | 处理 |
|---|---|
| ≤24h | 正常进主表，标“今天/昨天” |
| 2–7 天 | 进主表但标“需复核”，下单前必须重新核价 |
| 8–30 天 | 不进主表，进“历史价参考” |
| >30 天或已过期 | 进“史低价参考”，标注“仅供参考，时效性不强，不急用可以蹲” |

“历史价参考”折叠区格式：

```
<details>
<summary>历史价参考（已失效，仅作判断）</summary>

- 2026-10-28 超能双离子 11斤 28.95 元（5.26 元/kg）
- 2026-10-09 同款 29.45 元

</details>
```

**史低价**（>30 天或已过期）单独一段，标注：

```
<details>
<summary>史低价参考（仅供参考，时效性不强，不急用可以蹲）</summary>

- 2025-11-11 同款 24.90 元（4.53 元/kg）— 双11 历史低
- 2025-06-18 同款 26.10 元（4.75 元/kg）

</details>
```

## 结论段

表格后必须给：

1. **最推荐**：哪个平台/哪一行，为什么（价格 + 难度 + 时效）。
2. **次选**：如果最推荐的条件不满足（没会员/不想凑单），退而求其次选哪个。
3. **风险**：券可能失效、库存、账号条件、风控。

## 报告结构

1. **结论**：最推荐哪个、到手价、为什么（价格 + 难度 + 时效）。
2. **比价表**：主表（当前可买）。
3. **历史价与假优惠**：30/90 天低、史低、是否“划线价不可信”。
4. **风险与失效**：券到期、库存、地区、会员条件。
5. **局限**：哪些平台没查、哪些价格未核验。
6. **来源**：每条数据的链接和日期。

不要只甩一张表；结论和局限必须写。

## 禁止

- 不要把标价当到手价。
- 不要把过期爆料列进主表“让用户白开心”；但过期价要保留进史低参考，不能直接丢掉。
- 不要用“大概率”“应该”描述价格；不确定就写“未核验”。
- 不要编造链接或 SKU。
