# 价格口径与假优惠识别

## 到手价

```
实付 = 标价 + 运费 − 店铺券 − 平台券 − 立减 − 补贴 − 淘金币/红包（能抵的）
```

- 券门槛、凑单金额、会员条件必须写出来，不能只写一个数。
- 凑单：凑后实付 ÷ 目标商品数量；不能把凑单品成本全算给目标商品。

## 单价

元/kg、元/L、元/片、元/件；多件装先折单件再比，不同规格绝不混算。

## 假优惠识别（确定性规则，不靠 agent 复盘）

数据源：慢慢买（30/60/180 天新低、历史新低标签）、什么值得买（历史低价标签）、当前页划线价。

记录四个数：当前价 `C`、30 天最低 `L30`、90 天最低 `L90`、史低 `Lmin`，都带日期。

| 条件 | 判定 |
|---|---|
| `C ≤ L30` | 真优惠（近期低位） |
| `C ≤ L90 × 1.05` | 接近低位，可考虑 |
| `C > L90 × 1.2` | 非低位，标“不建议现在买” |
| 页面“X折”按划线价算，但划线价 > 历史最高成交价 | 标“划线价不可信/疑似假优惠” |
| 拿不到历史价 | 写“未核验”，不能凭感觉说“便宜” |

补充：

- 慢慢买的“历史新低/30天新低/60天新低”标签直接采用，但必须带日期。
- 什么值得买的“绝对值/历史低价”只作旁证，最终以慢慢买历史价为准。
- 同一商品不同规格（5.5kg vs 5.9kg）分别算，不能拿大瓶单价压小瓶。

## 风险标记

- 券今日到期、库存 <10、地区限制、会员专享
- 拼团/福袋/直播间红包 → 标“不确定”，不进主表排序
- 二手：成色、验货宝、卖家信用、是否拆修、是否国行
